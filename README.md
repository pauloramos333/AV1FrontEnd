# Academia e Saúde

## Sobre o projeto

Este projeto foi desenvolvido com o tema **Academia e os benefícios da atividade física para a saúde**.

O objetivo é apresentar informações sobre exercícios físicos, seus benefícios para a saúde e diferentes tipos de atividades que podem ser realizadas em uma academia.

O projeto foi desenvolvido utilizando apenas **HTML5**, sem a utilização de CSS.
